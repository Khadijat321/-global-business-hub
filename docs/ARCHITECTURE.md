# Global Business Hub Architecture

## Architecture Style

Modular monolith.

## Applications

### Web
Next.js with TypeScript.

### API
NestJS with Node.js and TypeScript.

## Database

PostgreSQL.

## ORM

Prisma.

pnpm workspaces.

- Security by design
- Separation of concerns
- Reusable components
- Scalable database design
- Maintainable code
- Automated testing
- Clear API contracts
