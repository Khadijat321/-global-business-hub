# Global Business Hub (GBH)

Global Business Hub is an international business discovery,
visibility and networking platform.

## Vision

To connect businesses, customers, suppliers, service providers
and partners across the world through one trusted digital ecosystem.

## Core Features

- Global business directory
- Business registration and profiles
- Product and service showcases
- International business discovery
- Customer enquiries
- Business networking
- Business verification
- Reviews and ratings

## Technology Stack

- Frontend: Next.js and TypeScript
- Backend: NestJS and Node.js
- Database: PostgreSQL
- ORM: Prisma
- Package Manager: pnpm
- Version Control: Git and GitHub

## Project Structure

- apps/web: Web application
- apps/api: Backend API
- packages/shared: Shared utilities
- packages/types: Shared TypeScript types
- packages/config: Shared configurations
- docs: Project documentation
